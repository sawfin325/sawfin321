## FAQ

**Do you work with Elementor, Divi, or Gutenberg?**
Yes. I customize builder sites and block themes. For complex features I add custom code so you are not stuck fighting the builder.

**Will my site break when WordPress or the theme updates?**
I use a child theme and proper hooks instead of editing parent-theme files. That keeps updates safer.

**Can you fix bugs on an existing site?**
Yes. Send the URL, the broken page, and what you expected to happen. I will confirm the cause and the package before work starts.

**Do you write custom plugins?**
Yes, for Standard and Premium when a small plugin is cleaner than theme functions.

**Do you provide source files?**
You keep the code I add to your WordPress install. I can also deliver a zip of the child theme or plugin.
