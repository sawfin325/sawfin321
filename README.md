# Chrono24 HTML demo

Static recreation of the Chrono24 marketplace layout. Open `index.html`.

Includes the dark header, **Buy a watch** mega menu (brands, categories, services), and a full **Gauri** product line listed with Buy pages (demo checkout, no real payment).

Not affiliated with Chrono24 GmbH.

## Pages

- `index.html` — homepage plus the Gauri collection
- `search.html` — search and filters
- `listing.html` — listing detail and buy box
- `brands.html` — all maisons
- `sell.html` / `security.html` / `magazine.html` / `collection.html` / `pulse.html`
- `login.html` / `faq.html` / `about.html` / `contact.html` / `apps.html`
