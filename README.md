# Meridian

A static HTML luxury-watch marketplace inspired by the public layout of [chrono24.com](https://www.chrono24.com/).

Open `index.html` in a browser. No build step, no server, no payment processing.

Meridian is an original front-end demo. It is **not affiliated with Chrono24 GmbH**. Maison names appear as catalogue labels the way any watch market would list them.

## Pages

- `index.html` — homepage (hero, brands, certified, stats, buyer protection, explore, popular models, reviews, magazine, Instagram, videos, how it works)
- `search.html` — search and filters
- `listing.html` — listing detail and buy box
- `sell.html` — sell a watch
- `security.html` — buyer protection / escrow
- `brands.html` — all maisons
- `deals.html` — lower-priced listings
- `magazine.html` / `article.html` — editorial
- `collection.html` — saved watches (browser storage)
- `pulse.html` — market overview
- `login.html` / `account.html` — demo account
- `faq.html` / `about.html` / `contact.html` / `apps.html`

## Photos

Product and lifestyle images are original generated photographs, not scraped from Chrono24.
